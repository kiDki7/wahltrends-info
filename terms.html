Terms / API information

Wahltrends is a privately operated project run by one individual in Germany. It publishes factual summaries of current German election polling trends as short-form videos on its own social-media channels.

Private API client

The Wahltrends API client uses YouTube API Services to manage and upload content to the operator's own authorized YouTube channel. The API client is not offered as a public service and is not available for third-party use.

The website itself does not provide accounts, uploads or interactive API functionality to visitors. Visitors cannot log in or authorize a YouTube account through this website or client.

YouTube terms

Use of YouTube and the YouTube API Services is subject to the YouTube Terms of Service and the applicable YouTube API Services policies. By using the private API client, its operator agrees to comply with those terms and policies.

These terms describe the public website and do not create a customer account, public API offering or service relationship with visitors.
