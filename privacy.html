Datenschutzerklärung

Informationen zur öffentlichen Website und zur ausschließlich durch den Betreiber erfolgenden Nutzung der YouTube API Services.

Stand: 19. August 2026

1. Öffentliche Website

Diese Website ist eine statische GitHub-Pages-Website. Sie bietet keine Benutzerkonten, eigenen Kontaktformulare, Anmeldefunktionen oder eingebetteten Social-Media-Widgets.

Wahltrends setzt auf dieser Website keine eigenen Analyse- oder Trackingdienste, keine Werbetracker und keine Marketing-Cookies ein. Beim Abruf kann GitHub als Hostinganbieter technisch erforderliche Zugriffsdaten, etwa IP-Adresse, Zeitpunkt und angeforderte Datei, verarbeiten. Weitere Informationen enthält die Datenschutzerklärung von GitHub ↗.

2. YouTube API Services

Wahltrends verwendet YouTube API Services. Der YouTube-API-Client ist kein öffentlich angebotener Dienst und wird ausschließlich durch den Betreiber für den eigenen autorisierten Wahltrends-Kanal verwendet.

Die Autorisierung erfolgt über OAuth. Der Client kann die Identität und die für den Betrieb erforderlichen Daten des autorisierten Kanals abrufen sowie Wahltrends-Videos auf diesen Kanal hochladen und verwalten. Externe Besucher können über diese Website kein Google- oder YouTube-Konto autorisieren.

3. Zugriff, Verwendung und Weitergabe von API-Daten

Der Client greift auf die Kanalidentität, zugehörige Kanalinformationen und die für Upload und Verwaltung der Wahltrends-Videos erforderlichen Daten zu. Diese Daten werden ausschließlich zur Verwaltung des eigenen autorisierten Kanals verarbeitet.

API-Zugangsdaten und OAuth-Tokens werden geschützt gespeichert und nicht öffentlich zugänglich gemacht. YouTube-Anmeldedaten wie Benutzername oder Passwort werden nicht erhoben. API-Daten werden nicht verkauft, nicht für Werbung verwendet und nicht an externe Dritte weitergegeben. Google und YouTube verarbeiten Daten, soweit dies zur Bereitstellung der YouTube API Services erforderlich ist.

4. Speicherung und Löschung

Autorisierte API-Daten werden nur so lange gespeichert, wie dies für den beschriebenen Zweck und nach den YouTube-API-Richtlinien erforderlich ist. Gespeicherte API-Daten werden innerhalb der dort vorgesehenen Zeiträume aktualisiert oder gelöscht; soweit keine speziellere Regel gilt, erfolgt dies spätestens nach 30 Kalendertagen.

Nach einem Widerruf über die Google-Kontoeinstellungen werden zugehörige gespeicherte API-Daten und nicht mehr benötigte Autorisierungstokens so bald wie möglich und spätestens innerhalb von 30 Kalendertagen gelöscht. Der autorisierte Kontoinhaber kann zusätzlich über die im Impressum genannte Kontaktmöglichkeit die Löschung gespeicherter API-Daten verlangen; eine solche Löschanfrage wird so bald wie möglich und spätestens innerhalb von sieben Kalendertagen umgesetzt. Dies löscht keine bei YouTube selbst gespeicherten Inhalte.

5. OAuth-Zugriff widerrufen und Kontakt

Der OAuth-Zugriff kann jederzeit unter Verbindungen zu Drittanbietern im Google-Konto ↗ eingesehen und entfernt werden. Fragen oder Beschwerden zu den Datenschutzpraktiken können über die im Impressum genannte Kontaktadresse gestellt werden.
