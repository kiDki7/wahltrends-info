Datenschutzerklärung

Diese Erklärung informiert über die Datenverarbeitung auf der öffentlichen Wahltrends-Website und bei der ausschließlich durch den Betreiber erfolgenden Nutzung der YouTube API Services.

Stand: 19. August 2026

1. Öffentliche Website

Diese Website ist eine statische Informationsseite. Sie bietet keine Benutzerkonten, Anmeldefunktion, Formulare oder öffentlich nutzbare Software. Wahltrends erhebt über die Website nicht aktiv personenbezogene Daten und setzt keine eigenen Cookies ein.

Es werden keine Analyse-, Tracking-, Werbe- oder Marketingdienste verwendet. Die Website wird über GitHub Pages bereitgestellt. Beim Abruf können technisch erforderliche Verbindungsdaten durch den Hosting-Anbieter verarbeitet werden. Nähere Informationen enthält die Datenschutzerklärung von GitHub ↗.

2. Verwendung der YouTube API Services

Wahltrends verwendet YouTube API Services. Der zugehörige API-Client ist ein nicht öffentlich angebotenes Werkzeug und wird ausschließlich vom Betreiber selbst eingesetzt, um den eigenen autorisierten Wahltrends-Kanal zu verwalten.

Die Autorisierung erfolgt über OAuth. Der Client kann die Identität des autorisierten YouTube-Kanals abrufen und Videos auf diesen Kanal hochladen. Externe Nutzer können ihre Google- oder YouTube-Konten nicht mit Wahltrends verbinden.

3. Verwendung und Schutz von API-Daten

Über die YouTube API Services abgerufene Daten werden ausschließlich für die Verwaltung und Veröffentlichung von Inhalten auf dem eigenen Wahltrends-Kanal verwendet. API-Daten werden nicht verkauft und nicht zu Werbe- oder Marketingzwecken genutzt.

OAuth-Zugangsdaten und Autorisierungstoken werden nicht veröffentlicht und geschützt gespeichert. Der Zugriff ist auf den Betreiber und den beschriebenen Zweck beschränkt.

4. OAuth-Zugriff verwalten und widerrufen

Der erteilte OAuth-Zugriff kann jederzeit in den Google-Kontoeinstellungen für Verbindungen zu Drittanbietern ↗ eingesehen und widerrufen werden.

5. Richtlinien von Google und YouTube

  • Google-Datenschutzerklärung ↗
  • YouTube-Nutzungsbedingungen ↗
  • Drittanbieterzugriff im Google-Konto verwalten ↗

6. Kontakt

Bei Fragen zu dieser Datenschutzerklärung kann der Betreiber über den öffentlich verlinkten Wahltrends-Kanal auf YouTube ↗ kontaktiert werden.
