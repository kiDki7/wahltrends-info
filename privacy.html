Datenschutzerklärung

Informationen zur öffentlichen Website, zur betreiberinternen Nutzung der YouTube API Services und zu einer lediglich möglichen künftigen TikTok-Anbindung.

Stand: 19. August 2026

1. Verantwortlicher und Kontakt

Verantwortlich für diese Website und den Wahltrends-API-Client ist der im Impressum genannte Betreiber. Dort finden Sie auch die Kontaktadresse für Datenschutzanfragen, Beschwerden, Widerrufe und Löschanfragen.

2. Öffentliche Website und GitHub Pages

Diese Website informiert über das privat betriebene Projekt Wahltrends. Sie ist eine statische GitHub-Pages-Website und bietet keine Benutzerkonten, eigenen Kontaktformulare, Anmeldefunktionen oder eingebetteten Social-Media-Widgets. Wahltrends setzt hier keine eigenen Analyse- oder Trackingdienste, Werbetracker oder Marketing-Cookies ein.

Beim Abruf stellt der Browser eine Verbindung zu GitHub her. GitHub protokolliert bei Besuchen von GitHub Pages die IP-Adresse zu Sicherheitszwecken und kann weitere technisch erforderliche Nutzungs- und Zugriffsdaten verarbeiten, insbesondere Datum und Uhrzeit der Anfrage, aufgerufene Seite oder Ressource, Referrer sowie Geräte- und Browserinformationen.

Soweit diese Verarbeitung dem Betreiber zuzurechnen ist, dient sie der zuverlässigen, sicheren und technisch fehlerfreien Bereitstellung der Website. Rechtsgrundlage ist Art. 6 Abs. 1 Buchst. f DSGVO; das berechtigte Interesse liegt in der sicheren und funktionsfähigen Veröffentlichung des Informationsangebots. Empfänger und Hostinganbieter ist GitHub. GitHub kann Daten auch außerhalb des Europäischen Wirtschaftsraums verarbeiten und beschreibt hierfür verwendete Garantien in seiner Datenschutzerklärung.

Der Betreiber erhält von GitHub Pages keine eigenen Server-Protokolle und speichert solche Zugriffsdaten nicht selbst. Die Speicherdauer bei GitHub richtet sich nach dem jeweiligen Verarbeitungszweck und gesetzlichen Pflichten. Einzelheiten enthält die GitHub General Privacy Statement ↗.

3. YouTube API Services und OAuth

Wahltrends verwendet YouTube API Services. Der YouTube-API-Client ist kein öffentlich angebotener Dienst. Er wird ausschließlich durch den Betreiber für dessen eigenen, von ihm autorisierten Wahltrends-Kanal verwendet; externe Besucher können weder über diese Website noch über den Client ein Google- oder YouTube-Konto autorisieren.

Die Autorisierung erfolgt über OAuth und nur im Umfang der erteilten Berechtigungen. Der Client kann die Kanalidentität und die für den Betrieb erforderlichen autorisierten Kanal- und Veröffentlichungsdaten abrufen sowie Videos auf den autorisierten Kanal hochladen und dort verwalten. Dabei kann er den von YouTube zurückgegebenen Video-Identifier als externen Veröffentlichungs-Identifier im Veröffentlichungsstatus oder in der Veröffentlichungshistorie speichern.

4. Verwendung, Schutz und Weitergabe von YouTube-Daten

Die Daten werden ausschließlich verwendet, um den eigenen autorisierten Wahltrends-Kanal zu identifizieren sowie vom Betreiber veranlasste Uploads und deren Verwaltung durchzuführen und nachzuhalten. Autorisierte Daten sind nur für den autorisierenden Betreiber zugänglich.

API-Zugangsdaten, Client-Secret und OAuth-Tokens werden geschützt und nicht öffentlich zugänglich gespeichert. Der Client erhebt oder speichert keine YouTube-Anmeldedaten wie Benutzername oder Passwort. API-Daten werden nicht verkauft, nicht für Werbung oder Profilbildung verwendet und nicht unbefugt an Dritte weitergegeben. Daten werden nur an Google beziehungsweise YouTube übermittelt, soweit dies zur Nutzung der YouTube API Services erforderlich ist, oder wenn eine gesetzliche Pflicht besteht.

5. Speicherung, Aktualisierung und Löschung von YouTube-API-Daten

Autorisierungstokens dürfen nur so lange gespeichert werden, wie dies für den von einer aktiven Autorisierung gedeckten Zweck erforderlich ist. Andere gespeicherte autorisierte API-Daten – hierzu kann auch ein aus einer Upload-Antwort stammender Video-Identifier gehören – müssen, soweit keine besondere Richtlinienausnahme greift, spätestens nach 30 Kalendertagen gelöscht oder über die YouTube API aktualisiert werden. Nicht autorisierte API-Daten dürfen ebenfalls nur vorübergehend und höchstens 30 Kalendertage gespeichert werden, bevor sie gelöscht oder aktualisiert werden.

Für einen direkten Widerruf gegenüber dem API-Client kann der autorisierte Kontoinhaber die Kontaktadresse im Impressum verwenden. Der Betreiber widerruft das Token dann unverzüglich gegenüber Google und löscht alle aufgrund dieser Autorisierung abgerufenen oder gespeicherten autorisierten Daten so bald wie möglich, spätestens innerhalb von sieben Kalendertagen.

Alternativ kann der Zugriff auf der vorgeschriebenen Google-Seite für Sicherheits- und Kontoberechtigungen ↗ entzogen werden. Nach einem dortigen Entzug werden die aufgrund der Autorisierung gespeicherten, nutzerbezogenen API-Daten so bald wie möglich und spätestens innerhalb von 30 Kalendertagen gelöscht. Der Client muss dazu regelmäßig prüfen, ob seine Autorisierungstokens noch gültig sind.

Eine ausdrückliche Löschanfrage für beim API-Client gespeicherte nutzerbezogene Daten kann ebenfalls über das Impressum gestellt werden. Sie wird so bald wie möglich, spätestens innerhalb von sieben Kalendertagen, umgesetzt. Die Löschung beim API-Client löscht keine Inhalte, die bei YouTube selbst gespeichert sind; dafür müssen die Funktionen von YouTube oder eines hierzu autorisierten API-Clients verwendet werden.

7. TikTok Developer Services – derzeit nicht aktiv

Wahltrends nutzt die TikTok Developer Services derzeit nicht produktiv. Es werden aktuell keine TikTok-API-Daten, Zugriffs- oder Aktualisierungstokens verarbeitet, keine Inhalte automatisiert über eine TikTok API veröffentlicht und es liegt keine Aussage über eine erfolgreiche TikTok-Prüfung, Freigabe oder Auditierung vor.

Eine künftige Anbindung käme erst nach der erforderlichen technischen Einrichtung, Autorisierung und – soweit erforderlich – Prüfung oder Freigabe durch TikTok in Betracht. Abhängig von der dann tatsächlich eingesetzten Funktion könnten ausschließlich für das autorisierte Veröffentlichen folgende Daten verarbeitet werden: open_id, Access Token und Refresh Token, für die Veröffentlichung erforderliche Creator-Informationen, Datenschutz- und Veröffentlichungsoptionen, Beitragsmetadaten, Veröffentlichungs-Identifier und -status sowie die zu übertragende Videodatei.

Tokens und Secrets würden geschützt, serverseitig und nicht öffentlich zugänglich gespeichert. TikTok-Daten würden nur für den autorisierten Veröffentlichungszweck verwendet, nicht verkauft, nicht für Werbung oder Profilbildung genutzt und nur an TikTok, technisch notwendige Empfänger oder aufgrund gesetzlicher Verpflichtung weitergegeben. Die Autorisierung wäre widerruflich; nach Widerruf oder Beendigung würden nicht mehr erforderliche Daten nach den dann geltenden TikTok-Regeln und gesetzlichen Vorgaben gelöscht. Vor jeder produktiven Aktivierung wird diese Datenschutzerklärung an die tatsächlich umgesetzte Verarbeitung, Rechtsgrundlage, Empfänger und Speicherdauer angepasst.
