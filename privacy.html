Privacy Policy

Last updated: 19 August 2026

This policy describes the limited data practices of the Wahltrends website and its private YouTube API client.

Website

The website is a static GitHub Pages site. It does not provide user accounts, public login, forms, interactive API functionality or customer services. No personal information from external users is collected through this website. The site uses no analytics, tracking cookies, advertising technologies or other tracking tools.

Private YouTube API client

The Wahltrends API client uses YouTube API Services. It is a private tool used only by the operator to manage and upload Wahltrends videos to the operator's own authorized YouTube account and channel.

OAuth is used to authorize the application. The application may obtain the identity of the authorized channel and upload videos to that channel. It does not offer YouTube account authorization to members of the public, and no third party can authorize their YouTube account through this client.

OAuth credentials and tokens are stored privately as protected GitHub Actions secrets and are not exposed publicly. API data is used only for the stated operation of the private client. It is not sold or shared with third parties.

Revoking access

The operator can revoke the client's Google account permissions at any time through Google's account security permissions page. This page is also the appropriate place for an authorized account holder to review and revoke third-party access.
