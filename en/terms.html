Wahltrends

Terms and API Information

Information about the website, its use of YouTube API Services, and a possible future TikTok integration.

Last updated: 19 August 2026

1. Project and website

Wahltrends is a privately operated information project in Germany. The website is not a publicly offered API service. Visitors cannot create user accounts, log in, or authorize YouTube or TikTok accounts.

2. YouTube API Services

YouTube API Services are used exclusively by the operator to validate the operator's own authorized Wahltrends channel, check the status of previously uploaded videos, and upload prepared videos. The API client is not offered for use by visitors or any other third party.

OAuth configuration is supplied through the YOUTUBE_CLIENT_ID, YOUTUBE_CLIENT_SECRET, and YOUTUBE_REFRESH_TOKEN environment variables; YOUTUBE_CHANNEL_ID is a non-secret repository variable. The refresh token is not stored in Automation State. Access tokens created from it are held only in memory.

The client uses only the following Google and YouTube endpoints:

  • POST https://oauth2.googleapis.com/token
  • POST https://oauth2.googleapis.com/revoke
  • GET https://www.googleapis.com/youtube/v3/channels?part=id,snippet&mine=true
  • GET https://www.googleapis.com/youtube/v3/videos?part=status&id=…
  • POST https://www.googleapis.com/upload/youtube/v3/videos?uploadType=resumable&part=snippet,status
  • PUT requests to Google-provided resumable-upload session URLs

No endpoint for deleting YouTube videos or subsequently changing their visibility is used. When YOUTUBE_PUBLIC_PUBLISHING_ENABLED=true, authorization is valid, and YOUTUBE_CHANNEL_ID matches the authorized channel, publish-ready videos are automatically published publicly without per-video confirmation. Private diagnostic runs remain private.

Automation State stores only YouTube video IDs in platform publication state and publication history, plus sanitized API error text; channel information and refresh tokens are not stored there. Manual diagnostics log channel and video IDs in their execution logs. Video IDs and API errors are removed locally after 21 calendar days without refreshing their retention period. Cleanup runs during weekly/run and publish-ready without using YouTube API quota.

youtube-revoke can first pull bot-state. It then sends the configured refresh token to Google's revocation endpoint, immediately removes locally stored YouTube API data, records authorization loss in State schema 7, saves and pushes the cleaned state, and reports sanitized counts. Cleanup proceeds even if the token is already invalid, while persistence failures are reported as errors. An invalid_grant during OAuth refresh triggers the same immediate cleanup and blocks uploads; temporary network and HTTP 5xx failures do not. A new valid refresh token allows the next enabled publish-ready run to revalidate the channel, clear the marker, and resume automatic publishing.

Internal Wahltrends history and Facebook and Instagram state remain intact; only external YouTube IDs and YouTube API errors are removed. Neither local cleanup nor OAuth revocation deletes videos already stored by YouTube.

Use of the YouTube API client is subject to the YouTube Terms of Service ↗. Every user of the API client is bound by those terms. The operator is currently the sole user. Further information about data processing is available in the Privacy Policy.

3. TikTok Developer Services – not currently active

Wahltrends does not currently use TikTok Developer Services in production and does not offer TikTok publishing functionality. Future use would be considered only after complete technical setup, authorization of the relevant TikTok account, and any review, approval, or audit required by TikTok.

Use of the TikTok platform by account holders is subject to the TikTok Terms of Service for the EEA ↗. Any future use of TikTok Developer Services would additionally be subject to the TikTok Developer Terms of Service ↗, the applicable developer policies, and TikTok documentation.

Wahltrends is not affiliated with, sponsored by, endorsed by, or otherwise supported by TikTok unless TikTok expressly confirms otherwise. Preparing these legal pages does not constitute approval or endorsement by TikTok.

4. Nature of the content

Wahltrends presents published election polls and their development for informational purposes and in a factual manner. The content does not constitute a voting recommendation.

Polling figures reflect opinions at the time of each survey. They are neither a guarantee nor a prediction of the actual outcome of an election.
