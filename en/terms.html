Wahltrends

Terms and API Information

Information about the Wahltrends information service and the API services currently used or planned.

Last updated: 23 August 2026

1. Project and website

Wahltrends is a privately operated information project in Germany. The website is not a publicly offered API service. Visitors cannot create user accounts, log in, or authorize external accounts through this website.

2. Planned Google Trends API and Wahltrends attention index

Wahltrends plans to use the Google Trends API for a weekly “Politicians in Trend” format. API access is currently being requested under Google's alpha-access program. The feature has not yet been integrated into production.

The intended use is to retrieve aggregated Google Trends values for search interest in selected German politicians or clearly assigned political search terms. The analysis is intended to be limited to Germany and fixed weekly periods.

The Google Trends values are planned to be combined with aggregated Wikipedia page views. Wahltrends will use these data to calculate a proprietary attention index and a weekly ranking with changes compared with the previous week. Google Trends serves as a signal for active search interest, while Wikipedia page views serve as a complementary signal for information interest.

The resulting index measures public attention. It is not a measure of popularity, approval, voting intention, or an election-outcome forecast. Wahltrends publishes its own calculations, rankings, and visualizations and does not provide third parties with access to the Google Trends API itself.

Any use will take place only in accordance with the applicable Google terms and requirements of the alpha-access program. Further information is available in the Privacy Policy.

3. YouTube API Services

Wahltrends uses YouTube API Services exclusively for its own authorized Wahltrends channel. The service is used to upload prepared content, check publication status, and technically manage publishing. It is not offered as a public function for third parties.

Authorization is handled through Google OAuth. Access credentials and authorization tokens are stored securely. Google or YouTube accounts cannot be connected through the public Wahltrends website.

Wahltrends processes only the channel, video, and status information required to operate the YouTube integration. Further information about data processing, storage, and revocation is available in the Privacy Policy.

Use is subject to the YouTube Terms of Service ↗ and the applicable YouTube API Services Developer Policies ↗.

4. TikTok Developer Services – not currently active

Wahltrends does not currently use TikTok Developer Services in production. Future use would be considered only after the necessary technical setup, authorization, and any review or approval required by TikTok.

Any future use would be subject to the applicable TikTok terms, developer terms, and developer policies. Wahltrends is not affiliated with, sponsored by, or supported by TikTok unless TikTok expressly confirms otherwise.

5. Nature of the content

Wahltrends presents published Bundestag and state-election polls, their development, and in future its own analyses of political search and information interest for informational purposes and in a factual manner. The content does not constitute a voting recommendation.

Polling figures reflect opinions at the time of each survey. They are neither a guarantee nor a prediction of the actual outcome of an election. The planned Wahltrends attention index describes relative attention only and must not be interpreted as a popularity, approval, or voting-intention score.
