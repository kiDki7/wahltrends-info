Terms and API Information

Brief information about the website and its use of YouTube API Services.

Last updated: 19 August 2026

1. Project and website

Wahltrends is a privately operated information project in Germany. The website is not a publicly offered API service. Visitors cannot create user accounts, log in, or authorize YouTube accounts.

2. YouTube API Services

YouTube API Services are used exclusively by the operator to manage the operator's own authorized Wahltrends channel. The API client is not offered for use by visitors or any other third party.

By using the API client, its operator agrees to be bound by the YouTube Terms of Service ↗. Further information about data processing is available in the Privacy Policy.

3. Nature of the content

Wahltrends provides factual information about published election polls and their development. The content does not constitute an electoral recommendation or endorsement.

Poll values reflect opinions at the time of the respective survey. They are neither a guarantee nor a prediction of an actual election result.
