Privacy Policy

Information about the public website and the operator-only use of YouTube API Services.

Last updated: 19 August 2026

1. Public website

This website is a static GitHub Pages site. It does not provide user accounts, proprietary contact forms, login functions, or embedded social media widgets.

Wahltrends does not use its own analytics or tracking services, advertising trackers, or marketing cookies on this website. When the site is accessed, GitHub as the hosting provider may process technically necessary access data such as the IP address, time, and requested file. Further information is available in the GitHub General Privacy Statement ↗.

2. YouTube API Services

Wahltrends uses YouTube API Services. The YouTube API client is not a publicly offered service and is used exclusively by the operator for the operator's own authorized Wahltrends channel.

Authorization is handled through OAuth. The client can retrieve the identity and operationally necessary data of the authorized channel and can upload and manage Wahltrends videos on that channel. External visitors cannot authorize a Google or YouTube account through this website.

3. Access, use, and sharing of API Data

The client accesses the channel identity, associated channel information, and the data required to upload and manage Wahltrends videos. This data is processed solely to manage the operator's own authorized channel.

API credentials and OAuth tokens are stored securely and are not made publicly accessible. YouTube login credentials such as usernames or passwords are not collected. API Data is not sold, used for advertising, or shared with external third parties. Google and YouTube process data where necessary to provide the YouTube API Services.

4. Storage and deletion

Authorized API Data is stored only for as long as necessary for the stated purpose and in accordance with the YouTube API policies. Stored API Data is refreshed or deleted within the periods set out in those policies and, unless a more specific rule applies, no later than 30 calendar days.

After access is revoked through the Google Account settings, related stored API Data and authorization tokens that are no longer required are deleted as soon as possible and within 30 calendar days. The authorized account holder may also request deletion of stored API Data using the contact details in the Legal Notice; such a deletion request is completed as soon as possible and within seven calendar days. This does not delete content stored by YouTube itself.

5. Revoke OAuth access and contact

OAuth access can be reviewed and removed at any time under Third-party connections in the Google Account ↗. Questions or complaints about these privacy practices can be submitted using the contact address in the Legal Notice.
