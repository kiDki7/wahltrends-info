Project information

Wahltrends

Wahltrends automatically prepares concise, factual summaries of current German election polls and their development. The summaries are based on publicly available polling data.

About the project

Content created from the polling data is published on Wahltrends' own social media channels. Wahltrends is a privately operated project in Germany.

The presentations provide neutral information about published polling figures and their development.

This website

  • does not offer user accounts or a public login,
  • does not provide a public API or upload function,
  • does not allow third parties to authorize their social media accounts.

YouTube API Services

The YouTube API client is used exclusively by the operator for the operator's own authorized Wahltrends channel. Further details are provided in the Privacy Policy and the Terms and API Information.
