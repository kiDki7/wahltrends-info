Wahltrends

Wahltrends automatically prepares current German polling data and political trends as concise, traceable and factual social-media content. The content is based on publicly available data and is published on Wahltrends' own channels.

Federal and state polling trends

Wahltrends regularly publishes prepared polling trends for federal elections. Published state-level polls are now also processed for German states with upcoming state elections and published as separate state polling trends.

The federal trend includes all Bundestag polls from the previous 14 days, using only the most recent poll from each polling institute and weighting all institutes equally. For each party, the simple average of the values actually reported is calculated; missing values are not treated as zero. Changes are compared with the same 14-day trend from seven days earlier.

Data from dawum.de (Open Database License: odbl.dawum.de) · own calculation.

The visualizations provide neutral information about published polling figures and their development. Wahltrends is a privately operated project in Germany.

Planned extension: Politicians in trend

The next planned extension is a weekly attention ranking of German politicians. It is intended to show which politicians currently generate particularly strong public search and information interest.

The planned Wahltrends attention index is intended to combine Google Trends data on search interest in Germany with aggregated Wikipedia pageviews. Google Trends is intended as a signal for active search interest, while Wikipedia pageviews provide a complementary signal for information interest.

The Google Trends API would be used exclusively to retrieve aggregated trend values for selected political search terms, calculate weekly comparisons and a top-10 ranking, and publish the resulting visualizations on Wahltrends' own social-media channels. No personal Google user data would be retrieved, stored, or combined into user profiles.

The attention index is explicitly not intended to measure popularity, voting intention, or political approval. The Google Trends API is not yet integrated for this feature; API access is being requested for this planned extension.

YouTube API Services

The YouTube API client is used exclusively by the operator for the operator's own authorized Wahltrends channel. When public YouTube publishing is explicitly enabled, authorization is valid, and the configured channel ID matches, the client automatically publishes prepared videos without per-video confirmation. Private diagnostic runs remain private. Further details are provided in the Privacy Policy and the Terms and API Information.
