# Wahltrends

Wahltrends ist ein privat betriebenes Informationsprojekt, das regelmäßig kompakte und neutral dargestellte Trends aktueller deutscher Wahlumfragen auf den eigenen Social-Media-Kanälen veröffentlicht.

Die öffentliche Projektseite ist unter <https://kidki7.github.io/wahltrends-info/> erreichbar.

Dieses Repository enthält ausschließlich die öffentliche Informationsseite sowie die zugehörigen Datenschutz- und API-Hinweise. Die Website besteht aus statischem HTML und CSS und verwendet keine Tracker, Analysedienste, Werbung oder externe Abhängigkeiten.
